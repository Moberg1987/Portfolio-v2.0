Сделай полный QA этого портфолио (статический сайт: index.html + case-*.html + src/) и почини безопасные ошибки за один прогон.

Цель: убрать битое, неточности, мусорные/пустые ссылки, явные косяки. Ничего не ломать визуально и по поведению.

Это НЕ редизайн и НЕ рефакторинг архитектуры.
Не меняй композицию, шрифты, цвета, анимации, отступы «на вкус».
Не переписывай большие куски HTML/CSS/JS без нужды.

Порядок работы:
1) Сначала аудит (прочитай страницы и проверь пути ассетов).
2) Потом правь только safe-фиксы.
3) Сомнительное — в список «нужно решение», не трогай.

Проверь обязательно:
- Битые href/src (файла нет, опечатка в пути)
- Пустые #, javascript:void, ссылки «в никуда», нерабочие внешние URL если очевидно сломаны
- Перекрёстные ссылки между кейсами (логика «следующий/связанный кейс»)
- Обложки/видео: файл на месте, теги video корректны (если autoplay — muted+loop+playsinline)
- Одинаковые ?v= у общих CSS/JS на всех HTML
- Явные текстовые опечатки / копипаст-мусор / дубли alt/aria если мешают
- Битые импорты/селекторы в main.js только если реально ломают UI
- Лишние console / закомментированный мусор — только если мешает, не чисти «ради чистоты»

Safe-фиксы (делай сразу):
- починить путь к существующему файлу
- убрать/исправить явно мёртвую ссылку
- выровнять ?v= CSS/JS между страницами
- поправить опечатку в видимом тексте, если смысл ясен
- починить отсутствующий атрибут, из‑за которого ломается поведение

Не трогай без спроса:
- тексты кейсов «на красоту»
- порядок блоков / сетку / токены дизайна
- новые фичи
- git commit/push

В конце отчёт строго так:
## Исправлено
- пункт (файл)

## Нужно твое решение
- пункт (почему не правил)

## Не трогал / ок
- коротко
